# Change Log

All notable changes to `@homebridge-plugins/homebridge-openeo` will be documented in this file.

## v1.0.0 (2026-11-09)

### Added

- First release, from @Wazza151's OpenEO plugin
- A charge now on/off tile, a Car Connected sensor and a Charging Schedule switch
- A Charger Problem sensor that opens on a mains fault, or when the charger is offline
- Live watts and kWh over Matter, and an experimental Matter EV charger mode
- Finds the charger on the network by itself
- A status page with recent charging sessions in the Homebridge UI
